# claude-kit-template

A GitHub template repo for starting Claude projects the same way every time. It holds the kit (`KIT.md`) and every file in the kit's repo layout, with its `<PLACEHOLDERS>` left in.

Create a new project from it:

```bash
gh repo create OWNER/name --template MineGene/claude-kit-template --private
```

Then follow `KIT.md`, starting at stage 2.
